# Assure

**Status: work in progress — this is the Phase 1 scaffold, no model logic yet.**

A synthetic bank loan portfolio, an IFRS 9-style expected-credit-loss (ECL) model built
from scratch in Python, and a data-assurance/model-review layer that tests the model the
way an auditor would.

See `plan.md` (in the parent folder) for the full build plan. A complete README —
methodology, screenshots, live dashboard link, "why I built this" — will replace this
stub in Phase 8, once there's something to show.
